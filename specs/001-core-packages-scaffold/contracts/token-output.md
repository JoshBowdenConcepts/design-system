# Contract: Generated Output Shapes

Defines what each package's generate/build step MUST emit. All paths are
relative to `packages/<layer>/`. Everything under `dist/` is generated and
gitignored (FR: never hand-edited).

## tokens — web output

### `dist/web/tokens.css` (FR-006a)

CSS custom properties only. Structure:

```css
/* defaults */
:root {
  --ds-placeholder: 0;
  /* …one line per token… */
}

/* breakpoint axis (example block; present even if empty for scaffold) */
@media (min-width: 48rem) {
  :root { /* overrides */ }
}

/* color-mode axis */
[data-theme="dark"] {
  :root { /* overrides */ }
}

/* feature axis */
.ds-feature-example {
  /* overrides */
}
```

Rules:
- Every property name is prefixed `--ds-`.
- No CSS Modules, no class-scoped component styles, no hardcoded literals beyond
  the token values themselves.
- Scaffold emits at least the one placeholder token in `:root`. Axis blocks MAY
  be empty but the generator MUST support emitting into them.
- Regenerating unchanged source → identical file (reproducibility).

### `dist/web/index.js` + `index.d.ts`

- Default/named export of the token values as a typed object tree, e.g.
  `export const tokens = { placeholder: 0 } as const`.
- `index.d.ts` exports the token schema types from `src/types.ts`.

## icons — web output

- `dist/web/index.js` + `index.d.ts`: React components generated from
  `src/svg/*.svg`. Scaffold: `export const PlaceholderIcon: (props: SVGProps) => JSX.Element`.
- Components reference token CSS vars (`fill: var(--ds-…)`) where colour is
  needed — never hardcoded hex.

## components — web output

- `dist/web/index.js` + `index.d.ts`: React components compiled from
  `src/*.tsx`. Scaffold: `export const Placeholder: (props) => JSX.Element`
  rendering a `<div>` whose style consumes `var(--ds-placeholder)`.
- No hardcoded design values (Principle I).

## iOS output (all three packages)

`dist/ios/DesignSystem<Layer>/<Layer>.swift` — stub level:

```swift
// Generated by @design-system/<layer>. Do not edit.
public enum DesignSystem<Layer> {
    // tokens only, scaffold:
    public static let placeholder: Double = 0
}
```

Rules:
- One namespace enum per package.
- tokens: placeholder constant(s) mirroring the web token values (same value,
  generated from the same source — Principle II).
- icons/components: empty namespace enum is acceptable for the scaffold (stub).
- Referenced by the matching target in the repo-root `Package.swift`.

## Root `Package.swift`

- `swift-tools-version:5.9`.
- 3 library products + 3 targets, `path` → `packages/<layer>/dist/ios/DesignSystem<Layer>`.
- Target deps per `dependency-matrix.md`.
- `swift package describe` succeeds after `pnpm build` (SC-005).

## Empty-but-well-formed guarantee (FR-005)

If a package's `src/` had zero authored artifacts, its build MUST still produce:
- `dist/web/index.js` (empty barrel `export {}`) + `index.d.ts`
- tokens: `dist/web/tokens.css` with an empty `:root {}` block
- `dist/ios/DesignSystem<Layer>/<Layer>.swift` with an empty namespace enum
…and exit 0.
